# Edit and build the championship

The source projects in this repository define the Night City Street Series.
The repository name is a distribution label; in-game titles come from the authored
race and series display text.

## Setup

Keep the sibling Race Builder and its native dependencies available. Install
the parent `ghostline77` JavaScript workspace with `npm ci`, then run from
this repository:

```powershell
cargo build --release --locked --manifest-path ../race-builder/Cargo.toml
```

Road drawing uses a native road network generated by Race Builder. Vehicle
selection uses the published Vehicles catalogue. See the
[Race Builder guide](https://github.com/ghostline77/race-builder) for these inputs.

## Edit in the browser

```powershell
../race-builder/target/release/ghostline-race-builder.exe serve --workspace projects --roads path/to/roads.json --vehicles ../vehicles/dist/catalogue
```

Open <http://127.0.0.1:8795/>. Select a race, edit its course and checkpoints,
then save. Inspect the activation point, player arrival, grid and crowd placements
separately. A road centreline does not establish clearance from barriers.

[The series manifest](../projects/series/modio_championship.json) defines order,
messages, final reward and Quest Core slot 1. Preserve project IDs and progression
identities when changing titles or instructions.

## Validate and build

```powershell
../race-builder/target/release/ghostline-race-builder.exe validate-series projects/series/modio_championship.json --projects projects
../race-builder/target/release/ghostline-race-builder.exe build-series projects/series/modio_championship.json --projects projects --out builds/championship --game 'path/to/Cyberpunk 2077'
```

Use a new output directory. The build samples native road surfaces and generates
race resources, localization, progression and package reports. Population-owned
actors and their standing workspots belong to this quest package. Their placement
changes do not require rebuilding Quest Core.

## Install for local cross-platform testing

Install Ghostline Quest Core and use the generated `modio/` ZIP. Extract its
contents into the game's `r6/c77` directory, preserving its package subfolder
and `tweaks` layout. Do not flatten the ZIP or install a second copy through the
normal PC mod directory.

Slot 1 must be allocated to this championship. Another quest pack replacing the
same slot conflicts with it. The core provides startup; the race package provides
the populated slot and gameplay resources.

## Verify the series

Use a separate test save. Check the introduction and Race #1 map marker, then drive
each course. Check countdown, checkpoint order, recovery, finish cleanup and a
retry after losing. After winning, check the next invitation and objective.

Win all nine to check the one-time bonus and replay availability. Reload the
completed save and confirm the bonus does not repeat. Check provided-car cleanup,
NPC occupancy, starting-grid clearance and road-marker coverage in game.
Native package verification does not replace console testing.
